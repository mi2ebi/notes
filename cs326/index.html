history of programming languages

tower of babel (genesis 11): people used to all speak the same language and were trying to build a tower to heaven, but god didn't like that so he gave them all different languages

in the 1940s all we had was machine language. you'd literally just be writing binary. by the 50s we made some assembly languages that were specific to the computer (room) you were using

high level languages were created in the 60s. eg fortran (engineering), lisp (proofs), cobol (business), simula (models & oop)

systems programming eg c was invented in the 1970s around when unix was. (unix was made in three weeks!)

computers got a ton faster in the 80s, so programs were getting very complicated. so we invented object oriented programming and c++. originally you could only transpile your c++ into c and then the c compiler would run it

java was invented by sun microsystems in the 1990s and got very popular because it could run on many different OSes. "write once, run everywhere". people also started wanting to write programs for browsers! but browsers were all different and unstandardized. so they decided to split frontend from backend and did the backend in java!

microsoft and apple had a war about who was better. microsoft decided to remove some of the java libraries, but this meant it didn't run everywhere! they had to pay apple $1.95 bn, and they forked java into c#

java was also used for adobe flash (but there it was named actionscript)

the web was getting pretty stable. they invented html4, css, and the document object model (dom) between 1994 and 1998

in 2009 oracle bought sun microsystems, so now they own java

paradigms

in theory all programming languages are equivalent. in practics they have differenw ways of thinking about things

compiled language
turn stuff into syntax trees and symbol tables and do all the codegen and optimizing and whatever
interpreted language
just shove the code through a vm
hybrid
do the first bits of compiling and them shove it in a vm
