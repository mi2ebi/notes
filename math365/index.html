ch1 matrices and systems of linear equations

motivation

solve for \(x\): \[10x + 20 = 15 → 10x = -5 → x = -\frac12\]

solve for \(x, y\): \[ \left\{ \begin{align*} 2x + 10y &= 10\\ 3x - y &= 25 \end{align*} \right. \]

1.1 intro to matrices

linear equation
in \(n\) unknowns, an equaiton (that can be written) in the form \[a₁x₁ + a₂x₂ + … + aₙxₙ = b\] where \(aᵢ\) and \(b\) are the given coefficients, and \(xᵢ\) are the unknowns
system of linear equations
a set of linear equations. an \((m × n)\) system has \(m\) linear equations and \(n\) unknowns \[ \left\{ \begin{align*} a₁₁x₁₁ + a₁₂x₁₂ + … + a₁ₙx₁ₙ &= b₁ \\ a₂₁x₂₁ + a₂₂x₂₂ + … + a₂ₙx₂ₙ &= b₂ \\ …& \\ aₘ₁xₘ₁ + aₘ₂xₘ₂ + … + aₘₙxₘₙ &= bₘ \\ \end{align*} \right. \]

ex. find two different solutions of \(3x₁ + ex₂ = 10\) and describe the solution set

solving for \(x₁\) gives us \[x₁ = \frac{10}3 - \frac e3 x₂\]

for \(x₂ = 0\) we get \(x₁ = \frac{10}3\)

for \(x₂ = \frac{10}e\) we get \(x₁ = 0\)

the solution set is a line! with slope \(-\frac e3\) and “\(x₂\)-intercept” \(\frac{10}3\)

given a \((2 × 2)\) system of equations there are three possibilities:

  • there's exactly 1 solution
  • there aren't any solutions (parallel)
  • there are infinitely many solutions (exact same line)

a system is consistent if it has at least one solution and inconsistent if not
