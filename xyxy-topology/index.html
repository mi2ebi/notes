§2 functions

a rule of assignment is a subset \(r\) of a cartesian product \(C × D\), s.t. each element of \(C\) is the first coordinate of at most one pair in \(r\). the domain of \(r\) is \(C\) and the image set of \(r\) is the subset of \(D\) containing all the second coordinates of pairs in \(r\). i.e. \[\operatorname{domain} r = \left\{c \,\middle|\, ∃ d ∈ D.\; (c, d) ∈ r\right\}\] \[ \operatorname{image} r = \left\{d \,\middle|\, ∃ c ∈ C.\; (c, d) ∈ r\right\}\]

a function \(f\) is a rule of assignment \(r\) together with a set \(B\) that contains the image set of \(r\). "domain" and "image set" of \(f\) refer to those of \(r\), and \(B\) is the range of \(f\)

if \(A₀ ⊂ A\), the restriction of \(f\) to \(A₀\) is the function \(f|A₀ = \left\{(a, f(a)) \,\middle|\, a ∈ A₀\right\}\)

why in the world are we using \(ℝ̄₊\) for the nonnegative reals

\(f\) is injective if \([f(a) = f(a')] \implies [a = a']\), surjective if \(b ∈ B \implies ∃ a ∈ A.\; b = f(a)\), and bijective if both

it's not true in general that \(f⁻¹(f(A₀)) = A₀\) and \(f(f⁻¹(B₀)) = B₀\)

the identity function \(i_C\) on a set \(C\) maps all elements in \(C\) to themselves. given a function \(f : A → B\), it could have some left inverses \(g : B → A\) if \(g ∘ f = i_A\), and/or some right inverses \(h : B → A\) if \(f ∘ h = i_B\). (courtesy of rezuaq: a function with multiple right inverses is e.g. \(f : \{0, 1\} → \{0\}\) by \(x ↦ 0\), which has \(g(0) = 0\) and \(g'(0) = 1\))

§3 relations

a relation on \(A\) is a subset \(R\) of the product \(A × A\)

an equivalence relation on \(A\) is a relation \(∼\) with some extra properties:

reflexivity
\(∀ x ∈ A.\; x ∼ x\)
symmetry
\(x ∼ y \implies y ∼ x\)
transitivity
\(x ∼ y ∧ y ∼ z \implies x ∼ z\)

the equivalence class determined by \(x\) is the set \(E = \left\{y \,\middle|\, y ∼ x\right\}\). (the notation i learned for this was \(x̄\).) two equivalence classes \(E\) and \(E'\) are disjoint xor equal

a partition of a set \(A\) is a collection of disjoint nonempty subsets of \(A\) whose union is all of \(A\)

an order relation on \(A\) is another relation \(<\) with some other properties:

comparability
\(∀ x, y ∈ A\mathord:\; x ≠ y.\; [x < y ∨ y < x]\)
nonreflexivity
\(∄ x ∈ A.\; x < x\)
transitivity
\(x < y ∧ y < z \implies x < z\)

the open interval \((a, b)\) is the set \(\left\{x \,\middle|\, a < x < b\right\}\). if it's empty, we call \(a\) the immediate predecessor of \(b\) and \(b\) the immediate successor of \(a\)

suppose \(A\) and \(B\) are two sets with order relations \(<_A\) and \(<_B\). \(A\) and \(B\) have the same order type if there's a bijection \(f : A → B\) s.t. \[a₁ <_A a₂ \implies f(a₁) <_B f(a₂)\]

define an order relation \(<\) on \(A × B\) by defining \(a₁ × b₁ < a₂ × b₂\) if \[a₁ <_A a₂ ∨ a₁ = a₂ ∧ b₁ <_B b₂\] this is the dictionary order relation on \(A × B\)

lubp/glbp

suppose \(A\) is a set ordered by \(<\), and it has a subset \(A₀\). an element \(b\) is the largest element of \(A₀\) if \(b ∈ A₀\) and if \(x ≤ b\) for every \(x ∈ A₀\). similarly an element \(a\) is the smallest element of \(A₀\) if \(a ∈ A₀\) and if \(a ≤ x\) for every \(x ∈ A₀\). every ordered set has at most one largest element and at most one smallest element

\(A₀\) is bounded above if there is an element \(b\) of \(A\)‼️ s.t. \(x ≤ b\) for every \(x ∈ A₀\). if the set of all upper bounds has a smallest element, that element is the least upper bound / supremum of \(A₀\) and denoted by \(\sup A₀\). it may or may not be in \(A₀\). if it is, it's the largest element

similar for bounded below and infimum (\(\inf A₀\))

\(A\) has the least upper bound property if every nonempty subset \(A₀\) of \(A\) that is bounded above has a least upper bound. similar for greatest lower bound property
