5.7 poisson distribution

we take the binomial distribution and let \(n → ∞\) and \(p → 0\), get a stable number \(λ ≔ np\), and take the limit:

\[ \def\thelim{\lim_{\substack{n → ∞ \\ p → 0}}} \begin{align*} \thelim p(x) &= \thelim {n \choose x} pˣ (1 - p)ⁿ⁻ˣ \\ &= \thelim {n \choose x} \left(\fracλ n\right)ˣ \left(1 - \fracλ n\right)ⁿ⁻ˣ \\ … &= \frac{λˣ}{x!}e^{-λ} \end{align*} \]

remember \(\lim\limits_{n → ∞}\left(1 + \frac xn\right)ⁿ = eˣ\)

workplace accidents follow a poisson distribution since there are a lot of workplaces and individual accidents are unlikely

ch6 continuous probability distributions

6.1 uniform distribution

a random variable \(X\) follows the uniform probability distribution on the interval \([a, b]\) if its pdf looks like \[ f(x) = \begin{cases} \frac1{b - a}, & a ≤ x ≤ b \\ 0, & \text{otherwise} \end{cases} \]

\[ E(X) = \frac{a + b}2 \qquad \var(X) = \frac1{12} (b - a)² \]

6.2 normal distribution

the bell shaped one!

\[ f(x) = \frac1{σ\sqrt{2π}} e^{-\frac1{2σ²} (x - μ)²} = \frac{e^{-z²/2}}{σ\sqrt{2π}} \]

\(x\) can be any real number. we write \(X ∼ N(μ, σ²)\). \(E(X) = μ\) and \(\var(X) = σ²\)

the area under the curve is 1 (but the function has no closed-form integral) and there are points of inflection at \(x = μ ± σ\)

digit contest:
\(π = 3.14159265358979323...\)
\(e = 2.718281828459045...\)

a rv \(Z\) with \(μ = 0\) and \(σ = 1\) and its probability distribution is a standard normal probability distribution. the pdf of \(Z\) is \[ φ(Z) = \frac1{\sqrt{2π}}e^{-x²/2} \]

since it's not feasible to have tables for every possible normal distribution, we just have the one table for \(Z ∼ N(0, 1)\). we can standardize a normal distribution by mapping \(xᵢ ↦ zᵢ ≔ \frac{xᵢ - μ}σ\)

6.3 using N to approximate bin

if \(X ∼ \bin(n, p)\) it can be approximated by a normal distribution with \(μ = np\) and \(σ² = npq\) when \(np > 5\) and \(npq > 5\)

you might need a continuity correction of adding/subtracting 0.5

6.4 exponential distribution

for random phonemena involving time, eg device lifespan

\[ f(x) = \frac1θ e^{-x/θ} , \quad θ > 0 \]

if \(X\) follows this we write \(X ∼ \Exp(θ)\)

this is also called a laplace distribution

\(E(X) = θ\) and \(\var(X) = θ²\). the standard deviation is the mean! and mean > median

\[ F(X) = \begin{cases} 1 - e^{-x/θ}, & x ≥ 0 \\ 0, & x < 0 \end{cases} \]

after reparameterization \(λ = \frac1θ\) we can write \(f(x) = λe^{-λx}\). \(θ\) represents the mean time between events and \(λ\) represents the number of events per unit of time

the survival function / reliability is \(1 - F(x) =\) \[ F̄(x) = S(x) = ∫ₓ^∞ f(t) \;\mathrm dt = \exp(-λx) \]

a random variable is memoryless if \(P(X > s + t \mathbin| X > t) = P(X > s)\) for all \(s, t ≥ 0\)

6.5 gamma distribution

the gamma function is \(Γ(k) = ∫₀^∞ yᵏ⁻¹e⁻ʸ \;dy\) and has properties

  • \(Γ(k) = (k - 1)!\) for \(k ∈ ℕ₁\)
  • \(Γ(k + 1) = kΓ(k) = k!\)
  • \(Γ(1) = 0! = 1\) and \(Γ\left(\frac12\right) = \sqrtπ\)

the \(E(X)\) for the exponential distribution is, by definition, \[ ∫₀^∞ x\frac1θ e^{-x/θ} \;dx \]

if we let \(y = \frac xθ\), then \(x = yθ\) and \(dx = θ dy\), and therefore \[ \begin{align*} E(X) &= ∫₀^∞ θ y \frac1θ e⁻ʸ θ \;dy \\ &= θ ∫₀^∞ ye⁻ʸ \;dy \\ &= θ ∫₀^∞ y²⁻¹e⁻ʸ \;dy \\ &= θ Γ(2) = θ \end{align*} \]

a random variable follows the gamma distribution \(\Ga(α, β)\) if \(x ≥ 0\) \[ f(x) = \frac1{Γ(α)β^α} x^{α - 1} e^{-x/β} \]

\(\Ga(1, β) = \Exp(β)\)

on the wikipedia page for gamma distribution, this is the "shape-and-scale" gamma distribution; we are using \(β\) for scale but wikipedia uses \(β\) for rate and \(θ = 1/β\) for scale

\(E(X) = αβ\) and \(\var(X) = αβ²\)

ch8 samples and sampling distributions

random sample
a sample of size \(n\) (\(X₁, X₂, …, Xₙ\)) with probability function \(f(x)\) where each \(Xᵢ\) are independent and identically distributed (iid) with the population distribution
statistic
function of random variables in a sample. since it varies from sample to sample, it's a random variable
sampling distribution
probability distibution of a statistic
law of large mnumbers (LLN)
as \(n\) gets "large", a statistic approaches the parameter. eg \(x̄ → μ\) or \({\lim\limits_{n → ∞} \left|x̄ - μ\right|} = 0\)

\(\left|x̄ - μ\right|\) specifically is the sampling error, controllable by the sample size \(n\)

for a sample \(X₁, X₂, …, Xₙ\) from a normal distribution \(N(μ, σ²)\), then the sample mean \(X̄\) is normally distributed with \(E(X̄) ≡ μ_X̄ = μ\) and \(\var(X̄) ≡ σ_X̄² = \frac{σ²}n\)

the standard error \(σ_X̄ = \fracσ{\sqrt n}\)

if the population size is finite, we need to multiple the finite population correction, ie \(\var(X̄) = \frac{σ²}n\left(\frac{N - n}{N - 1}\right)\)

for any random sample with sufficiently large \(n ≥ 25\), \(X̄\) is approximately normally distributed with \(E(X̄) = μ_X̄ = μ\) and \(\var(X̄) = σ_X̄² = \frac{σ²}n\)

this is true no matter what the population distribution may be!!
well as long as \(σ² < ∞\)

central limit theorem (CLT)
\[ \lim_{n → ∞} P\left(\frac{X̄ - μ}{σ / \sqrt n}\right) = Φ(z) \]

ch9 estimation

estimator
formula used to estimate a parameter
estimate
a numerical value produced by an estimator. eg if a sample has \(X̄ = 162\) then \(μ̂ = 162\)

a single numerical value is called a point estimate. the accuracy is evaluated by the margin of error

margin of error
\(±1.96σ\) or \(±1.96s\)

an estimator \(θ̂\) is unbiased for the parameter \(θ\) if \(E(θ̃) = θ\)

an estimator \(θ̂\) is more efficient than another estimator \(θ̃\) if \(\var(θ̂) ≤ {\var(θ̃)}\)

we can also construct an interval around the point estimate that's likely to contain the real parameter. for a \(N(μ, σ²)\),

\[ P\left(-z_{α/2} < \frac{X̄ - μ}{σ/\sqrt n} ≤ z_{α/2}\right) = 1 - α \]\[ ⇔ P\left(X̄ - z_{α/2}\fracσ{\sqrt n} < μ ≤ X̄ + z_{α/2}\fracσ{\sqrt n}\right) = 1 - α \]

when the sample is drawn from a population the interval is not random anymore. it it called the \((1 - α) · 100\%\) confidence interval for \(μ\) and given by

\[ \left]x̄ - z_{α/2} \fracσ{\sqrt n}, x̄ + z_{α/2} \fracσ{\sqrt n}\right[ \]

ch10 testing

q: does a sample eg \(x̄ = μ̂\) show enough evidence to believe some statement about \(μ\)?

null hypothesis (\(H₀\))
the assumed-until-proven-otherwise fact that a hypothesis is false
alternative hypothesis (\(Hₐ\) or \(H₁\))
new evidence based on data about \(μ\)
type i error
\(α = P\left(\text{reject }H₀ \mathbin| H₀\text{ is true}\right)\)
false positive rate / level of significance. we want this as small as possible
type ii error
\(β = P\left(\text{¬reject }H₀ \mathbin| H₀\text{ is ¬true}\right)\)
false negative rate
power of the test
\(1 - β = P\left(\text{reject }H₀ \mathbin| H₀\text{ is ¬true}\right)\)

how to test stuff:

  1. two hypotheses \(H₀\) and \(H₁\)
  2. test statistics: use the statistic to find \(z\) or \(t\)
  3. critical value & rejection region from \(α\)
  4. make a statistical decision
  5. draw a conclusion
test form H0 H1 CV & RR
left-tailed \(μ = μ₀\) \(μ < μ₀\) \(z < -z_α\)
right-tailed \(μ > μ₀\) \(z > z_α\)
two-tailed \(μ ≠ μ₀\) \(z < -z_{α/2}\) or \(z > z_{α/2}\)
p-value
observed level of significance. = tail probability
small \(p\) value is evidence against the null hypothesis

testing qualitative/categorical data

we want to count the frequencies of things! since all we have is just the \(k\) categories

in 1900 karl pearson introduced the chi-squared test \[ χ² = ∑ᵢ₌₁ᵏ \frac{\left(Oᵢ - Eᵢ\right)²}{Eᵢ} \] where \(Oᵢ\) is the observed frequency and \(Eᵢ\) is the expected frequency

it's small if it fits the expectation/model and large when it doesn't

\(χ²\) tests are distribution-free

we can test indpendence given an \(r\mathord× c\) contingency table. let
\(fᵢⱼ =\) observed frequency for \(i\)th row and \(j\)th column
\(eᵢⱼ =\) expected frequency
d.f. \(= (r - 1)(c - 1)\)
